# Matbox 架构地图（公开展示版）

Matbox 是一个 AI 生成内容与 AI 员工调度平台。这里是它的**架构地图与流程演示**。

👉 **[打开架构地图](https://xyhzai.github.io/matbox-architecture/)**

## 里面有什么

- **架构依赖图** —— 全部模块、分组、以及"谁依赖谁"的真实关系；点任意模块可以看它自己的邻居关系图
- **13 张流程演示图** —— 按步骤播放，看每条链路真实怎么跑
- **代码持续质检与安全自检 Gate** —— 三个阶段（开发前 / 开发中 / 运行中）切换，以及"开发资料准备到什么程度"的逐项状态

## 这是展示版

实施细节（数据库表结构、API 端点、逐条施工面、工作包、运行指标）**不在这个仓库里**，
它们在 Matbox 的内部仓库。页面上被移除的位置都留了说明。

## 怎么本地打开

下载后**双击 `architecture_dependency_diagram.html`** 即可，不需要服务器。

---

由 `docs/_build_public_export.py` 从内部仓库自动生成，不是手工维护的副本。
